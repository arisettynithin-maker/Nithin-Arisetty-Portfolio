# Nithin Arisetty Portfolio

Premium Next.js portfolio site for Nithin Arisetty, designed as a standalone personal website for LinkedIn, CVs, and job applications.

## Stack

- Next.js 14 App Router
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run start
```

## Deploy

This project is ready for deployment on Vercel as a standard Next.js app.
